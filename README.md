An entry for [make.fun's "The Funniest Honest Appliance Error" bounty](https://make.fun/bounty/u-xvader-the-funniest-honest-appliance-error-adec4450).

The entry is one line: a washing machine's flat, resigned error message
about an unbalanced load. It tried seven times to redistribute the laundry.
The whole problem is one sock.

Run `python3 main.py` and it writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
